`wc.py` is a small word-count CLI (`python3 wc.py FILE...`). Add a `--json` flag. With it, print exactly one JSON array to stdout: one object per file in the given order with keys `file`, `lines`, `words`, `chars`, and, if more than one file was given, a final object with `file` set to `"total"`. A file that cannot be read must not abort the run: report it on stderr, leave it out of the output and the total, and exit with status 1 at the end (otherwise 0). The plain-text output must stay as it is.
