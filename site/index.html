35B on an 8 GB card

A mixture-of-experts model activates only 3B parameters per token. Attention stays on the GPU, experts are offloaded to RAM.

Speculative decoding

The model's own MTP head drafts two tokens ahead. 75 % are accepted: +14 % speed at 4K, +10 % at 32K.

A real agent

Built on Qwen Code: it edits files, runs commands, reads errors and fixes them. It asks before acting unless you choose --auto-edit or --yolo.

Terminal or browser

alia web opens the same agent as a web shell, bound to 127.0.0.1 only.

How it is built

Standing on proven open source.

Alia does not reinvent the agent loop or the inference engine. It adds what was missing: hardware detection, measured profiles, a safe server lifecycle and one command to start it all.

  1. Aliahardware detection · profiles · server lifecycle · branding
  2. Qwen Codeagent loop, tools, terminal UI, web shell
  3. llama.cppCUDA inference, expert offload, MTP drafting
  4. Qwen3.6 · Unsloth GGUFopen-weight model, dynamic 3-bit quantization
  5. Your GPUNVIDIA · Linux

Install

Up and running in four steps.

  1. Agent and downloader

    npm install -g @qwen-code/qwen-code@0.25.1
python3 -m pip install -U "huggingface_hub[cli]"

  2. llama.cpp with CUDA

    git clone https://github.com/ggml-org/llama.cpp ~/src/llama.cpp
cd ~/src/llama.cpp && git checkout a0e6dc7
cmake -S . -B build -DGGML_CUDA=ON -DCMAKE_BUILD_TYPE=Release
cmake --build build -j"$(nproc)" --target llama-server

  3. Alia

    git clone https://github.com/BEKO2210/alia
cd alia && ./install.sh && alia doctor

  4. Start

    alia

    The first start shows the exact model download (14.07 GB for the default profile) and asks before fetching anything.
